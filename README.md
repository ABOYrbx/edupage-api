# edupage-api

Standalone Multi-Account-Gateway für EduPage, optimiert für KI-Agenten.

## Quickstart
```bash
./scripts/install.sh
./scripts/run.sh
```
Backend: http://127.0.0.1:8787 (API unter /api/v1). Frontend Dev: http://127.0.0.1:5173.

Admin-Passwort steht in `backend/.env` (`ADMIN_PASSWORD`).

## API
Siehe `docs/API.md`. Agent-API ist drahtkompatibel zu EduFlow `/api/v1`.
